## Reusable implementation

`ArchitecturalPlan`: geometry, architectural detail, camera, room labels, classification, spatial fixture arrays and clipped field overlays. `Furniture`: vector drafting context. `StoryTitle`: consistent timed typography. `DesignBasis`: source/proposal/review annotation. `EndCard`: actual identity and proposed tagline. `theme.ts`: extracted brand tokens. `rooms.json`: frozen source polygons/classification evidence. `scripts/sound.py`: repeatable original score.
